# GAS バックエンド

このフォルダは、スプレッドシート側の Google Apps Script のコードです。
スクリプトエディタで直接編集すると差分が追えなくなるため、**変更はここで行い、
エディタに貼り戻す**運用にします。

| ファイル | 内容 |
|---|---|
| `code.gs` | 既存のバックエンド一式（データ取得・更新・初期セットアップ） |
| `ocr.gs` | 貸与書類の読み取り（Gemini API）※新規 |

---

## 書類の自動読み取りを有効にする手順

紙で届く貸与書類をスマホで撮影し、シリアル・契約番号・契約日を自動入力する機能です。
**読み取り結果は自動保存されません。** 必ず登録フォームに流し込み、目視で確認してから登録します。
シリアル番号は 0↔O、1↔I、8↔B の誤読が起こりうるためです。

### 1. Gemini APIキーを取得する

1. https://aistudio.google.com/apikey を開く（会社のGoogleアカウントで）
2. 「APIキーを作成」→ 表示されたキーをコピー

無料枠の範囲で使えます（この用途は月に数枚程度のため）。

### 2. APIキーをスクリプトプロパティに登録する

スプレッドシート → 拡張機能 → Apps Script → 左メニューの歯車（プロジェクトの設定）
→ 「スクリプト プロパティ」→ プロパティを追加

- プロパティ: `GEMINI_API_KEY`
- 値: 1でコピーしたキー

> キーはここに置けば、公開されている index.html 側には一切出ません。
> **index.html に直接キーを書かないでください**（GitHub Pagesで誰でも見られる状態になります）。

### 3. コードを貼り付ける

1. スクリプトエディタで「ファイルを追加 → スクリプト」→ 名前を `ocr` にする
2. `gas/ocr.gs` の中身を全部貼り付ける
3. 既存の `コード.gs` の `doPost` に、以下の分岐が入っているか確認する
   （`gas/code.gs` には追加済みなので、そのまま貼り替えてもよい）

```javascript
      case 'ocrDocument':          // 貸与書類の読み取り（ocr.gs）
        result = ocrDocument_(body);
        break;
```

### 4. 再デプロイする

デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ

**URLは変わりません。** 新規デプロイをするとURLが変わり、index.html の `GAS_URL` の
差し替えが必要になるので、必ず「デプロイを管理」から更新してください。

### 5. フロント側を有効にする

`index.html` の `OCR_ENABLED` を `true` に変更してコミット。

```javascript
const OCR_ENABLED = true;
```

社員カードの「＋ 機器を追加」に［書類を撮影 / 画像を選ぶ］ボタンが出ます。

## 動作の流れ

```
スマホで書類を撮影（最大5枚）
  → ブラウザ側で長辺1600pxのJPEGに縮小
  → GASへPOST（action: 'ocrDocument'）
  → Gemini APIへ画像を送信し、JSON形式で項目を抽出
  → 日付を yyyy/mm/dd に整形して返却
  → 読み取り結果を一覧表示 → ［入力する］で登録フォームへ流し込み
  → 目視で確認 → ［登録］で既存の addDevice によりシートへ書き込み
```

判読しにくい箇所があった機器には「要確認」バッジが付きます。その場合は
必ず現物のシリアルと照合してください。

## 精度が出ないときは

- `ocr.gs` の `OCR_MODEL` を `gemini-2.5-pro` に変更する（低速・高精度）
- 書類の様式が決まっているなら、`OCR_PROMPT` に「シリアル番号は
  『製造番号』欄に記載されている」のように書類固有の手がかりを追記する
