# GAS バックエンド

このフォルダは、スプレッドシート側の Google Apps Script のコードです。
スクリプトエディタで直接編集すると差分が追えなくなるため、**変更はここで行い、
エディタに貼り戻す**運用にします。

| ファイル | 貼り付け先 | 内容 |
|---|---|---|
| `code.gs` | スクリプト `コード.gs` | バックエンド一式（アクセス制御・データ取得・更新・初期セットアップ） |
| `ocr.gs` | スクリプト `ocr.gs` | 貸与書類の読み取り（Gemini API） |
| `../index.html` | **HTML `index.html`** | 画面一式。GASから配信するのでここに貼る |

---

## アクセス制限のしくみ

画面（`index.html`）は GitHub Pages ではなく**Apps Script のウェブアプリから配信**します。
こうするとURLそのものが Google ログインで守られ、社外の人はログイン画面から先に進めません。

守りは2段構えです。

1. **デプロイ設定** … アクセスできるユーザーを「会社ドメイン内の全員」にする（Googleが認証する）
2. **許可アドレスシート** … ログインできた人のうち、`許可アドレス` シートに載っている人だけ通す

**会社ドメインのアカウントでも、許可シートに載っていない人は入れません。**
1段目のログインは通っても2段目で弾かれ、「このアプリを使う権限がありません」という
画面（ログイン中のアドレス付き）が出ます。

> **スプレッドシートのオーナーは常に許可されます。**
> 許可シートを空にしても管理者まで締め出されないようにするためです。

### 利用者を増やす / 減らす

`許可アドレス` シートにアドレスを1行ずつ足すだけです（再デプロイは不要）。
シートが無ければ初回アクセス時に自動で作られ、オーナーのアドレスが入ります。

| メールアドレス | 名前 | 最終アクセス | 備考 |
|---|---|---|---|
| sannomiya@now-village.jp | （管理者） | 2026/09/03 | 自動で追加されました |
| tanaka@now-village.jp | 田中 | 2026/08/28 | 2026/09 追加 |
| suzuki@now-village.jp | 鈴木 | 2026/04/11 | ←半年使っていない |

外したいときは行を削除します。次のアクセスから使えなくなります。

### 有効期限について

**期限は設けていません。** 承認した人は、管理者が行を消すまでずっと使えます。
都度のメール認証もありません（Googleログイン済みならURLを開くだけで入れます）。

退職者は Workspace アカウントが止まった時点でログインできなくなるため、
消し忘れても社外から見られる状態にはなりません。

代わりに **最終アクセス** 列に使った日が自動で入ります。ときどき眺めて、
長く使っていない人の行を消す運用にしてください（同じ日に何度使っても書き込みは1回だけです）。

## 初回セットアップ / 認証を有効にする手順

**この順番で進めてください。** 先に再デプロイすると画面が出ません。

### 1. 画面ファイルを作る

1. スプレッドシート → 拡張機能 → Apps Script
2. 「ファイルを追加 → **HTML**」→ 名前を **`index`** にする（`.html` は自動で付きます）
3. 中身を全部消して、リポジトリの `index.html` を丸ごと貼り付ける

### 2. バックエンドを貼り替える

`gas/code.gs` の中身を `コード.gs` に丸ごと貼り付けて保存します。

### 3. デプロイ設定を変える

デプロイ → デプロイを管理 → 鉛筆マーク

| 項目 | 設定 |
|---|---|
| 実行するユーザー | **自分** |
| アクセスできるユーザー | **now-village.jp 内の全員** |
| バージョン | **新バージョン** |

→ デプロイ

- 「実行するユーザー: 自分」にしておくと、**利用者にスプレッドシートの権限を渡さずに済みます**。
  スプレッドシート自体は今まで通り管理者だけが開ける状態のままにできます。
- 「アクセスできるユーザー」に**ドメインの選択肢が出ない**場合は、Google Workspace ではなく
  個人の Google アカウントでスクリプトを持っている可能性があります。その場合は
  「Googleアカウントを持つ全員」を選べば、許可アドレスシートによる制限だけは効きます。
- **URLは変わりません。** 「デプロイを管理」から更新してください。

### 4. 動作を確認する

ウェブアプリのURLを開き、画面が出ることを確認します。

- 「画面ファイルがありません」と出る → 手順1のHTMLファイル名が `index` になっているか確認
- 「アクセスできません」と出る → `許可アドレス` シートに自分のアドレスを追加

### 5. GitHub Pages を止める

GitHub → Settings → Pages → Source を **None** にします。
あわせてリポジトリを **private** にしておくと確実です。

> リポジトリの `index.html` にはもう接続先URLが入っていないので、
> 単体で開いても「このページは単体では動きません」と出るだけでデータは見えません。
> それでも公開したままにしておく理由はないので、止めておいてください。

## 書類の自動読み取りを有効にする手順

紙で届く貸与書類をスマホで撮影し、シリアル・契約番号・契約日を自動入力する機能です。
**読み取り結果は自動保存されません。** 必ず登録フォームに流し込み、目視で確認してから登録します。
シリアル番号は 0↔O、1↔I、8↔B の誤読が起こりうるためです。

### 1. Gemini APIキーを取得する

1. https://aistudio.google.com/apikey を開く（会社のGoogleアカウントで）
2. 「APIキーを作成」→ 表示されたキーをコピー

無料枠の範囲で使えます（この用途は月に数枚程度のため）。

### 2. APIキーをスクリプトプロパティに登録する

スプレッドシート → 拡張機能 → Apps Script → 左メニューの歯車（プロジェクトの設定）
→ 「スクリプト プロパティ」→ プロパティを追加

- プロパティ: `GEMINI_API_KEY`
- 値: 1でコピーしたキー

> キーはここに置けば、画面側（`index.html`）には一切出ません。
> **index.html に直接キーを書かないでください。**

### 3. コードを貼り付ける

1. スクリプトエディタで「ファイルを追加 → スクリプト」→ 名前を `ocr` にする
2. `gas/ocr.gs` の中身を全部貼り付ける
3. 既存の `コード.gs` の `handleAction_` に、以下の分岐が入っているか確認する
   （`gas/code.gs` には追加済みなので、そのまま貼り替えてもよい）

```javascript
    case 'ocrDocument':          // 貸与書類の読み取り（ocr.gs）
      return ocrDocument_(body);
```

### 4. 再デプロイする

デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ

**URLは変わりません。** 新規デプロイをするとURLが変わり、社内に配ったリンクが
使えなくなるので、必ず「デプロイを管理」から更新してください。

### 5. フロント側を有効にする

`index.html` の `OCR_ENABLED` を `true` に変更してコミットし、スクリプトエディタの `index.html` にも貼り直して再デプロイ。

```javascript
const OCR_ENABLED = true;
```

社員カードの「＋ 機器を追加」に［書類を撮影 / 画像を選ぶ］ボタンが出ます。

## 動作の流れ

```
スマホで書類を撮影（最大5枚）
  → ブラウザ側で長辺1600pxのJPEGに縮小
  → GASへ送信（google.script.run / action: 'ocrDocument'）
  → Gemini APIへ画像を送信し、JSON形式で項目を抽出
  → 日付を yyyy/mm/dd に整形して返却
  → 読み取り結果を一覧表示 → ［入力する］で登録フォームへ流し込み
  → 目視で確認 → ［登録］で既存の addDevice によりシートへ書き込み
```

判読しにくい箇所があった機器には「要確認」バッジが付きます。その場合は
必ず現物のシリアルと照合してください。

## 精度が出ないときは

- `ocr.gs` の `OCR_MODEL` を `gemini-2.5-pro` に変更する（低速・高精度）
- 書類の様式が決まっているなら、`OCR_PROMPT` に「シリアル番号は
  『製造番号』欄に記載されている」のように書類固有の手がかりを追記する
